# 手机访问开发服务器

## 当前真实原因（已查证）

本机注册表里的防火墙规则：

```
[Block] python.exe  Dir=In  Profile=Private  Protocol=6(TCP)
        App=C:\users\1\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe
[Block] python.exe  Dir=In  Profile=Private  Protocol=17(UDP)
        同上
无 5210 的放行规则
```

而 5210 端口正是这个 python 在监听。**Windows 防火墙里 Block 优先于 Allow**，
所以只加放行规则不会生效，必须先把这两条 Block 删掉。

这类规则通常是：某次 python 首次监听端口时，Windows 弹出「是否允许访问网络」，
而当时点了「取消」——系统就记下了一条 Block。

## 为什么"关闭防火墙"或"换个 python 启动"没用

- 查过注册表，三个配置（域/专用/公用）的 `EnableFirewall` 都还是 **1**；
- `.venv\Scripts\python.exe` 实际加载的还是同一个解释器，
  进程镜像路径不变，Block 规则照样命中。

## 修复（需要管理员权限）

以管理员身份打开 PowerShell：

```powershell
# 1. 先看清楚这两条（应显示 python.exe + Block）
Get-NetFirewallRule | Where-Object {
  $_.DisplayName -eq "python.exe" -and $_.Action -eq "Block"
} | Format-Table DisplayName, Action, Direction, Enabled

# 2. 删掉
Get-NetFirewallRule | Where-Object {
  $_.DisplayName -eq "python.exe" -and $_.Action -eq "Block"
} | Remove-NetFirewallRule

# 3. 放行端口
New-NetFirewallRule -DisplayName "WorldBranch 5210" `
  -Direction Inbound -Protocol TCP -LocalPort 5210 -Action Allow -Profile Private
```

然后重启服务，手机访问 `http://<电脑IP>:5210/`。

如果重启服务时又弹出「是否允许访问网络」，**选「允许」，并勾上「专用网络」**——
再点取消就又生成一条 Block。

## 为什么之前打不开

`backend/run.py` 原来只监听 `127.0.0.1`，即"只接受本机连接"。
手机连过来时，本机根本没有在这个地址上应答，所以是**连不上**，不是页面出错。

现在已经改成监听 `0.0.0.0`（所有网卡），局域网内可以直接访问。

## 正确地址

启动 `python run.py` 后，控制台会打印：

```
WorldBranch 监听 0.0.0.0:5210
  本机：  http://127.0.0.1:5210/
  局域网：http://192.168.10.26:5210/   ← 手机用这个（需同一 Wi-Fi）
```

**手机上要输的是局域网地址**（本机当前是 `http://192.168.10.26:5210/`），
不是 `127.0.0.1`——那个地址在手机上指的是手机自己。

## 三个前提，缺一不可

1. **同一个网络**：手机连的 Wi-Fi 必须和电脑是同一个路由器（同一网段，
   通常是 `192.168.x.x`）。用手机流量访问不了。
2. **监听 0.0.0.0**：已改好。若想只允许本机，设 `$env:HOST="127.0.0.1"`。
3. **防火墙放行**：Windows 防火墙默认挡入站。第一次运行 python 时如果
   弹过"是否允许访问"，当时点了"取消"，就会一直被挡。

## 放行防火墙（需要管理员权限）

以管理员身份打开 PowerShell，任选一种：

**按端口放行（推荐，只开这一个端口）**

```powershell
New-NetFirewallRule -DisplayName "WorldBranch 5210" `
  -Direction Inbound -Protocol TCP -LocalPort 5210 -Action Allow -Profile Private
```

**或者放行 python.exe**

```powershell
New-NetFirewallRule -DisplayName "Python dev server" `
  -Direction Inbound -Program "B:\新项目开发\.venv\Scripts\python.exe" `
  -Action Allow -Profile Private
```

删掉规则：

```powershell
Remove-NetFirewallRule -DisplayName "WorldBranch 5210"
```

> 只对「专用网络」放行（`-Profile Private`）。如果电脑连的 Wi-Fi 被 Windows
> 识别为"公用网络"，这条规则不会生效——把网络类型改成专用即可。

## 排查顺序

在**手机**浏览器里依次试：

1. `http://192.168.10.26:5210/api/health`
   能返回 `{"project":"WorldBranch","status":"ok"}` → 通了，再去 `/` 
2. 打不开 → 先在**电脑**上试同一个地址：
   - 电脑也打不开 → 服务没起来，看控制台输出
   - 电脑能开、手机不能 → 几乎一定是防火墙或不在同一网段
3. 确认电脑 IP：`ipconfig`，看"IPv4 地址"。IP 会变（DHCP），
   换了网络要重新看。

## 想让手机在任何网络下都能访问

那需要把服务放到一台有公网地址的机器上，见 [部署说明](部署说明.md)。
本项目默认不做这件事。
